# Legend Arrow

A calm arrow-puzzle game for Android: clear arrows with an open path out, awaken legendary creatures, and collect them in a bestiary.

Status: pre-development. Design inputs live in `docs/design/`, the execution brief in `docs/brief/`. Claude Code builds the project milestone by milestone following `CLAUDE.md`; progress is tracked in `docs/PROGRESS.md`.

Built with Godot 4 (GDScript) · Android · GitHub Actions.
